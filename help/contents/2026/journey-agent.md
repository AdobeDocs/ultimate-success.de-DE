# Skalieren von Adobe-Agenten: Journey Agent

Erfahren Sie, wie Journey Agent Workflows in natürlicher Sprache mit menschlicher Aufsicht kombiniert, um die Erstellung, Analyse und Optimierung von Journey zu beschleunigen. Gewinnen Sie praktische Einblicke in Governance, Berechtigungen, Empfehlungstransparenz, Einverständnis und Überprüfung vor der Aktivierung.

>[!VIDEO](https://video.tv.adobe.com/v/3496957/?learn=on&enablevpops)

## Behandelte Themen

- Wie Journey Agent die Journey-Erstellung mit Eingabeaufforderungen in natürlicher Sprache optimiert.
- Die Bedeutung von Governance und menschlicher Aufsicht in KI-Workflows.
- Praktische Strategien zur Optimierung von Kunden-Journey.
- Einblicke in die KI-Architektur von Adobe, die Journey Agent unterstützt.

## Zielgruppe

Dieses Ereignis ist für Folgendes konzipiert:
- Administratoren
- Führungskräfte
- Benutzende

Geeignet für Einzelpersonen auf allen Erfahrungsstufen, vom Anfänger bis zum erfahrenen.

1. **Einführung in Journey Agent**
   - Überblick über KI-gesteuerte Workflows.
   - Die Rolle der menschlichen Aufsicht bei der Optimierung des Journey.
2. **Adobes KI-Architektur**
   - Data Foundation: AEP und RT-CDP.
   - Koordinierungsschicht: Agent Orchestrator.
   - Übersicht über Specialized Agents.
3. **Detaillierte Einblicke in Journey Agent**
   - Erstellung, Analyse und Optimierung von Journey.
   - Praktische Anwendungsfälle und Beispiele.
4. **Einführung und Bereitschaft**
   - Technische Voraussetzungen.
   - Organisatorische Bereitschaft.
   - Strategische Planung für die Implementierung.
5. **Governance und Berechtigungen**
   - Gewährleistung von Compliance und Markenstandards.
   - Transparenz bei KI-Entscheidungen.
6. **Nächste Schritte und Fragen und Antworten**
   - Ansatz der schrittweisen Einführung.
   - Sofortmaßnahmen für Organisationen.

In dieser Sitzung erfahren Sie, wie Journey Agent von Adobe Ihre Kundenerlebnisstrategien durch erweiterte KI-Funktionen transformieren kann.
