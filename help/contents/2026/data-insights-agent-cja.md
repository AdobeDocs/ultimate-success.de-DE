# Operationalisieren von Adobe Data Insights Agent in CJA

Erfahren Sie, wie Sie Adobe Data Insights Agent in Customer Journey Analytics in einen praktischen, täglichen Workflow verwandeln. In dieser Sitzung wird gezeigt, wie Teams natürliche Sprachaufforderungen verwenden können, um die Analyse zu beschleunigen, Einblicke in den Self-Service zu ermöglichen und die Abhängigkeit von manuellen Berichten zu reduzieren. Wenn Sie die Time-to-insight und die datengestützte Entscheidungsfindung in Ihrem Unternehmen verbessern möchten, müssen Sie dies unbedingt im Auge behalten.
