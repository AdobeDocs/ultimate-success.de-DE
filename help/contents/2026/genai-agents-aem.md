# Lernen Sie Ihre neuen Kollegen kennen: Die GenAI-Agenten von Adobe Experience Manager

In dieser Sitzung erhalten Sie einen Überblick über die neuen GenAI-Agenten in Adobe Experience Manager - was sie sind, wie sie verwendet werden können und wo sie die tägliche Arbeit messbar erleichtern. Durch eine Tour durch das Agentenprogramm und eine Live-Anleitung sehen die Teilnehmer, wie Agenten die Inhaltserstellung, Oberflächenqualität und Markenprobleme beschleunigen und Änderungen über Sites hinweg orchestrieren, während AEM das vertrauenswürdige Aufzeichnungssystem bleibt. Die Teilnehmer wissen, welcher Agent welches Problem löst und wie sie anfangen können.

>[!VIDEO](https://video.tv.adobe.com/v/3495848/?learn=on&enablevpops)

## Wichtige Themen

* Agenten sind Kollegen, keine Ersetzungen. Die Agenten beschleunigen und koordinieren die Arbeit, aber Sie behalten die Kontrolle und AEM bleibt das Aufzeichnungssystem. Sie beschleunigen die Inhaltserstellung und bringen Probleme ans Tageslicht. Die Menschen entscheiden immer noch.
* Der richtige Agent für den richtigen Job. Jeder Agent löst ein spezielles Problem: die Brand Experience Agent für die Markenkonsistenz von Inhalten, der Content Advisor Agent für Inhaltsanleitungen und -empfehlungen und der Governance Agent für Richtlinien, Berechtigungen und sichere Veröffentlichung. Zu wissen, welche Aufgabe passt, ist der praktische Kern der Sitzung.
* Fang klein an. Der empfohlene Anpassungspfad besteht aus einem Agenten, einem Workflow, echten Inhalten - und erweitert sich dann, wenn Ihr Team Vertrauen aufbaut und Ergebnisse sieht, anstatt alles auf einmal zu aktivieren.
